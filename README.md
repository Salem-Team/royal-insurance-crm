# ROOTK SYSTEMS × Royal Insurance — CRM Quotation

Independent Next.js quotation for **Royal Insurance** CRM.

This project is fully separate from other ROOTK quotations (SAFQA, maintenance center, etc.).

## Local

```bash
cd royal-insurance-crm-quotation
npm install
npm run dev
```

- Local: http://localhost:3057/
- Build: `npm run build`
